# RV Trip Planner

Mobile-friendly RV road drive-time map.

Current version:
- Search for a starting town, address, or campground
- Select 1–8 hours of driving
- Show a lightly shaded road-based reachable area
- Designed to work well on iPhone

This is a planning aid. The current routing does not yet account for RV height,
weight, propane restrictions, or other RV-specific road restrictions.

Planned additions include saved campgrounds, dates visited, favorites/want-to-visit
markers, multiple drive-time bands, and RV-specific routing features.
